# Lumby Labs

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static pages. The user approved a simple, clean documentation site on a public GitHub repository with GitHub Pages. Build directly with static HTML/CSS; Python standard-library templates keep shared navigation consistent.

## Users

RuneLite players discovering plugins and reading usage documentation or finding support.

## Product Purpose

An umbrella brand and documentation website for the user's RuneLite plugins. Start with Farming Run Profit and support additional plugins without changing the site structure.

## Capabilities and Constraints

Plugin index, individual plugin documentation, and support links. Use each plugin's GitHub Issues tracker for bug reports and feature requests. No accounts, billing, analytics, or custom support backend are required.

## Brand Commitments

The user chose Lumby Labs, a RuneScape-related name. The website should be simple. No logo, color system, or domain has been approved.

## Evidence on Hand

Farming Run Profit source and documentation: https://github.com/bshelton/farming-profit. Published Hub identifier: farming-profit-tracker. Plugin support: https://github.com/bshelton/farming-profit/issues. Live release verified in RuneLite's 1.13.4 published manifest. Do not invent plugins, download counts, testimonials, or release dates.

## Product Principles

Keep plugin installation and documentation easy to find. Explain inference and accounting limits plainly. Direct help requests to the right repository. Preserve semantic navigation and usable layouts on desktop and mobile.
