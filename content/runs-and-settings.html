Runs & settings

Control what gets counted and keep the ledger useful when your route changes.

Pause, resume, or delete

  • Pause: stops automatic tracking and idle completion. Manual corrections remain available.
  • Resume: starts with fresh tracking baselines. Activity during the pause is not added later.
  • Delete current run: removes the unfinished run after confirmation. It does not save it to History. Later farming can start another run automatically.
  • Delete from History: removes one saved run and updates the history total. The confirmation identifies the run. Deletion cannot be undone in the interface.

Correct an entry

Select Add / correct entry. Choose a cost or harvest, enter the item or GP adjustment, quantity and value, and give a reason. Negative corrections can reverse an overcount. Check the breakdown before adding a correction so you don’t record the same item twice.

Farming reminders

Optional reminders cover missing magic secateurs for supported crops, a closed herb sack during herb harvesting, and farming while paused. Carrying magic secateurs in your inventory counts; you don’t need to equip them to dismiss the reminder.

The three reminders default to on. The separate inventory outline for a closed herb sack defaults to off. Each can be changed in Settings.
