Farming Run Profit

See what your farming run earned, what you spent, and where the difference came from.

Get startedView in Plugin Hub

Farming Run Profit tracks harvest value and supplies used during a run. It keeps an itemized ledger and local history for each RuneScape profile, with manual corrections for anything the game doesn’t expose reliably.

What it tracks

  • Harvested produce, including repeat harvests from established fruit trees and cactus.
  • Visible seed and sapling consumption, supported compost treatments, and contextual gardener payments.
  • Consumed basalt, supported teleport tablets, and loose inventory teleport scrolls during an active run.
  • Herbs entering an open sack, using labeled Farming XP inference when no inventory gain is visible.

Built around a run

Start automatically when farming or start manually before your first teleport. Pause when you take a break, finish to save the run in History, and open the breakdown to see the items behind the total. Individual completed runs can be deleted with confirmation.

Profit is an estimate. The plugin uses GE price snapshots, not actual sale proceeds. Earlier planting costs and sale tax are not included. Read how accounting works.

Source and support
