Troubleshooting

Start with the recorded entries, then narrow down what the plugin could observe.

My harvest count looks wrong

Check whether the run was paused and inspect the ledger for observed versus inferred harvests. For a sack harvest, compare the combined inventory and sack increase. Add a correction only for the missing or extra amount, then report the crop and patch with those counts.

A teleport or supply cost is missing

Make sure the run was active and unpaused before using it, and that the relevant cost setting is enabled. Runes, jewellery charges, scroll-book uses, Fertile Soil and seed-box supplies need manual entries. See accounting coverage.

Profit is negative or lower than expected

Open View breakdown and compare harvests with supplies. Seeds for the next crop are charged to the current trip. GE estimates may differ from your actual purchase or sale prices. Review zero-price items and inferred sack entries.

My run finished between patches

Increase Finish after idle minutes in Settings, or pause the run for a longer break. Resuming does not backfill paused activity.

History and recovery

History is stored locally under RuneLite’s plugin-data/farming-profit-tracker directory, with separate files for each profile. A .json file is the primary history; a .backup file preserves an earlier validated copy. Temporary writes use .pending files.

If loading fails, tracking pauses to protect the saved data. Close the client and preserve the files before trying recovery. A backup may lack recent activity. Follow the recovery guide rather than deleting files or mixing different profiles.

Share useful diagnostics

Farming diagnostics is an optional setting that writes farming signal details at DEBUG level. Logging availability depends on how RuneLite was launched; enabling the setting alone may not expose debug output in a normal client session.

Report what happened and attach a screenshot first. Share only relevant farming log excerpts if available. GitHub Issues are public: don’t attach credentials, account identifiers, your entire RuneLite folder, or unrelated client logs.
