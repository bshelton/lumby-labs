Getting started

Install from the Plugin Hub, then track your first farming run.

Install the plugin

  1. Open your regular RuneLite client.
  2. Open Plugin Hub from the configuration sidebar.
  3. Search for Farming Run Profit and install it.
  4. Log in and open its farming icon in the sidebar.

Open the Plugin Hub listing. You do not need a development client or a separate downloaded JAR.

Start a run

With Automatic runs enabled, observed farming activity starts a run. To include your first teleport item, select Start run before using it. Travel is counted only while a run is active and unpaused.

Harvest, plant, and review

Harvest normally, then replant and compost as needed. The sidebar shows estimated profit, harvest value, supplies, and Farming XP. View breakdown opens the ledger. You can sort its columns, filter harvests or costs, and select a row for patch and tracking details.

Tracking runs in the background. You can switch to another sidebar plugin while harvesting. Player Lookup does not need to interrupt harvest tracking.

Finish and save

Select Finish run when you’re done. The run moves into History. Runs also finish after the configured idle period, which defaults to 10 minutes. A paused run does not finish from inactivity.

History and unfinished runs are stored locally, separately for each RuneScape profile. They are not synced across devices.
